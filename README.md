# Taskdeck releases

This repository is the public download channel for Taskdeck, a local-first execution workspace for developers.

- Downloads live under [Releases](../../releases). Each release carries the Windows x64 archive, its SHA-256 checksum, a provenance file, an SBOM, the EULA and third-party notices.
- The update manifest is at `channels/beta/latest.json`.

This repository contains no source code and accepts no contributions.
